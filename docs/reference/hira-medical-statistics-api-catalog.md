현재 MCP의 HIRA 도구는 **요양기관(약국/병원) 위치검색** 마스터 데이터만 제공. 요청된 **진료 실적 집계 통계**(질병·처방·비용)는 별개 데이터셋. 본 문서는 그 진료통계 API 개방 현황을 조사한 결과.

## 개요

- 제공기관: 건강보험심사평가원(HIRA). 전 국민 진료 청구데이터 집계 통계(개인정보 아님).
- **발급처: data.go.kr(공공데이터포털)** — 기존 MCP `DATA20_SERVICE_KEY` 재활용 가능.
- 유형: REST / XML, 실시간 갱신, **무료**.
- 트래픽 한도: 개발계정 10,000건/일, 운영계정은 활용사례 등록 시 증량.
- opendata.hira.or.kr 웹 OLAP(국민관심질병통계 등)은 화면 조회 전용 — 프로그래밍 접근은 아래 data.go.kr Open API가 정본.

## 연동 판단

- **요청("진료통계")은 REST API로 충족 가능.** 파일만 있는 게 아님 — 질병정보서비스가 상병코드별 성/연령/지역 통계를 REST로 제공.
- 난이도 낮음: 기존 공공데이터 스킬 도구에 3종(의약품사용·질병정보·진료행위) 추가. `DATA20_SERVICE_KEY` 공유, XML 파싱 패턴 동일. 기존 HIRA 지역검색 도구 옆에 배치.
- **함정**: 지역 파라미터가 raw sidoCd/sgguCd일 가능성 높음(기존 HIRA 도구의 Q0/Q1 무시 이슈와 동일). 한글 시도/시군구 → raw 코드 매핑 재활용 필요.
- 미확인: 정확한 파라미터명·응답 필드. Swagger UI / 활용가이드 docx(`OpenAPI활용가이드_질병정보서비스_20241011.docx`)에만 존재 — 구현 단계에서 확보.
